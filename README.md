BlankSpace — Browser Lab
A small educational website for learning about browser tabs, about:blank, Blob URLs, pop-up handling, and iframe sandboxing.
Features
Responsive dark interface
Interactive about:blank demonstration
Interactive Blob URL demonstration
Notes workspace with a plain-text download
Explanations of browser behavior and iframe security
No backend and no third-party dependencies
Run locally
Open index.html in a modern browser. Some browsers restrict pop-ups unless the button is clicked directly.
Publish with GitHub Pages
Create a GitHub repository named blankspace-browser-lab.
Add index.html and this README.md to the repository root.
Open Settings → Pages.
Select Deploy from a branch, choose main and /(root), and save.
Wait for the published URL to appear in the Pages settings.
Learning notes
about:blank is a blank browser document, not an invisibility feature.
Blob URLs point to browser-managed data and are not stealth links.
Browser extensions may observe tabs depending on their permissions and browser policies.
Iframes can be blocked by a destination site's policy. Sandboxing is a security feature; do not remove restrictions without understanding the consequences.
