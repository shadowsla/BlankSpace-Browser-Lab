BlankSpace Browser Lab

HTML · CSS · JavaScript

Explore how browsers create tabs and temporary documents. Try the demonstrations, inspect the results, and learn what each browser feature can—and cannot—do.

01 · About:blank

Open a new blank tab and write a small, self-contained learning page into it. Your browser may block pop-ups unless you click the button directly.

Concept: about:blank
A new document, not an invisibility mode.

The tab and its activity can still be visible to the browser and extensions with appropriate permissions.

02 · Blob URL

Create a temporary HTML document from a Blob, then open it in a new tab. Blob URLs are browser-managed references, not stealth links.

Concept: blob:
Temporary content generated in JavaScript.

The URL is associated with the page's browser context and can be revoked when no longer needed.

03 · Notes workspace

Write notes and download them as a plain-text file. This demo does not send your notes to a server.

04 · Learn the browser concepts

1
window.open()

Requests a new browsing context. It can return null when a pop-up is blocked, so check the result.

2
about:blank

A built-in blank document. JavaScript can write content into a newly opened blank page when browser rules permit it.

3
Blob URLs

A browser-created URL that points to data such as generated HTML. It is not the same as hosting a public website.

4
iframes and sandboxing

An iframe embeds another page. A sandbox restricts capabilities, but combining allow-scripts and allow-same-origin can weaken protections for same-origin content. External sites may also block embedding.

5
Frame-busting code

Checking window.top === window.self detects whether a page is framed in many ordinary cases. It does not hide a tab from extensions or make a page undetectable.

Remember: A page title, educational label, blank URL, or Blob URL does not prevent browser management software from observing a tab. Use school-managed tools according to your school's rules.
